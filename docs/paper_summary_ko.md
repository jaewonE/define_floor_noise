# 논문 요약(파이프라인 중심)

## 문제

본 논문은 아파트 건물의 **층간 충격 소음(inter-floor impact noise)** 문제를 저비용·실시간으로 다루는 시스템을 제안합니다. 센서 데이터를 서버로 전송해 처리하는 대신, **초저전력 MCU 보드에서 직접 추론을 수행(온센서 AI, on-sensor AI)** 하는 방식입니다.

## 입력 및 데이터 수집

- 하드웨어: IMU(관성측정장치)가 탑재된 Arduino Nano 33 BLE.
- 설치: 아래층(하층) 천장 여러 위치에 보드를 부착.
- 샘플링: 자이로스코프/가속도 스트림을 약 104 Hz로 수집하며, 운영상 약 10 ms 간격으로 샘플링.
- 정의된 활동 클래스(6종): 걷기(walking), 랜덤 걷기(random walking), 달리기(running), 망치 타격(hammer blow), 덤벨 굴리기(rolling dumbbell), 책상 끌기(desk drag).

## 데이터 처리 및 데이터셋

- 센서 윈도우(window) 길이 128을 사용하며, 입력 채널은 (x, y, z)입니다.
- 이진 분류 타깃: `Noise`(소음) vs `Silence`(무음).
- 논문에 보고된 데이터셋: 총 9,588개 윈도우, 학습/검증/테스트를 7:2:1로 분할.

## 모델

- CNN 기반 이진 분류기.
- 논문에 서술된 아키텍처:
  - Conv2D (3x3, 16 채널)
  - MaxPool2D (3x3)
  - Conv2D (2x2, 8 채널)
  - MaxPool2D (2x2)
  - Dense (16)
  - Dense (2, 출력 클래스)
- 손실/최적화: binary cross-entropy 및 경사 기반 최적화.
- 보고 성능: 정확도 약 99%, F1 약 0.98.

## TinyML 변환 및 배포

- 학습된 모델을 TensorFlow Lite(`.tflite`)로 내보냅니다.
- `.tflite` 파일을 `xxd -i`로 C 배열로 변환하여 펌웨어에 포함(임베딩)합니다.
- 임베디드 로직은 시간 윈도우 단위로 반복 판정 후, 임계값 기반 의사결정 로직을 적용하여 최종 층간소음 알림을 수행합니다.

## 런타임 로직

- 한 번의 추론은 128 샘플 윈도우를 사용합니다(약 10 ms/샘플 기준으로 약 1.28초).
- 논문 로직은 진동 임계값(threshold) + 반복 카운트 기반 로직을 사용하여, 여러 차례의 검사 결과를 종합한 뒤 최종 알림을 발행합니다.
- 상층(윗집) 디바이스로의 통지는 BLE를 사용합니다.

## 평가

- 6개 활동 클래스에 대해 현장(on-site) 테스트를 수행합니다.
- 논문 Table 1에는 600회 테스트에 대해 총 정확도 96%가 보고되어 있습니다.
